# News Ticker Gutenberg Block

A customizable Gutenberg block for displaying a news ticker with various animation effects, advanced content sourcing, and comprehensive styling options. This block is dynamically rendered using PHP.

## Description

The News Ticker Block allows you to create engaging and visually distinct news tickers directly within the WordPress Gutenberg editor. You can display posts from your site (with advanced selection controls), add multiple custom content items via a repeater, and choose from several animation styles. It's designed to be flexible, with controls for animation speed, direction, navigation, styling, and more.

## Features

*   **Dynamically Rendered:** Ensures easier updates and maintenance as the block's front-end HTML is generated by PHP.
*   **Multiple Animation Types:**
    *   Scrolling Ticker: Continuous horizontal scroll (left or right).
    *   Up/Down Ticker: Items transition vertically one by one.
    *   Left-Right Sliding Ticker: Items slide in horizontally one by one.
    *   **Typing Effect Ticker:** (Logic module and CSS created; final integration into `view.js` requires manual update by the user due to a tool limitation encountered during development. The necessary `view.js` code will be provided.)
*   **Adjustable Ticker Speed & Direction.**
*   **Navigation & Play/Pause Controls.**
*   **Pause on Hover Option.**
*   **Advanced Content Sourcing:**
    *   Dynamic Post Type selection.
    *   Taxonomy & Term selection (searchable).
    *   Specific Post selection (searchable by title).
    *   Custom Content Repeater (multiple RichText items).
    *   Queried posts are fetched and displayed by PHP, with custom content items appended after them.
*   **Comprehensive Styling & Typography Options:**
    *   **Ticker Container:** Control background color, padding, border.
    *   **Header Area & Heading:** Control background, padding, text color, font properties.
    *   **Content Items Area & Individual Items:** Control background, text/link colors, font properties.
    *   **Navigation/Controls Buttons:** Control background, text, border colors.
*   **Block Alignment:** Supports "Wide" and "Full" alignments.
*   **Customizable Display Elements:** Logo, "Breaking News" heading text, "Live" text, Date.

## Installation

### From WordPress Admin (Zip):
1.  Download the plugin as a ZIP file.
2.  Go to `Plugins > Add New` in WordPress admin.
3.  Click `Upload Plugin`, choose the ZIP, and activate.

### From Source (Development):
1.  Clone/download the repository.
2.  In the plugin's root directory (`news-ticker-block`), run:
    *   `npm install` (Installs dependencies like `@wordpress/scripts`, `uuid`).
    *   `npm run build` (for production) or `npm run start` (for development).
3.  Copy `news-ticker-block` directory to `wp-content/plugins/`.
4.  Activate from WordPress admin.

## Usage

1.  Open a post/page in the Gutenberg editor.
2.  Add the "News Ticker" block.
3.  **Configure the Ticker (Inspector Panel on the right):**
    *   **Ticker Settings Panel:** Animation type, speed, direction.
    *   **Content Source Panel:** Configure post type, taxonomy/terms, specific posts, or add custom items. Queried content should now display correctly on the front-end.
    *   **Styling Panels:** Customize container, header, content items, and controls appearance. (*Note: Editor preview may not reflect all style changes live.*)
    *   **Display Elements Panel:** Logo, heading text, "Live" text, date.
    *   **Ticker Controls Panel:** Navigation, play/pause, pause on hover.
4.  The block supports "Wide" and "Full" alignments via the block toolbar.
5.  Save and view on the front-end.

## Styling

Extensive built-in styling options are applied as inline styles from editor settings. Base structural styles and interactive effects (like link hovers) are in `style.scss`. Override via theme CSS if needed.

## Known Issues / Limitations (Current Version)

*   **Typing Animation Integration:** The core logic and CSS for the "Typing Effect" animation are complete. However, due to a tool limitation during development, the final JavaScript changes in `view.js` to activate and manage this animation require manual application. The necessary `view.js` code will be provided separately.
*   **Seamless Scroll Animation:** May require fine-tuning for perfect seamlessness in all visual scenarios.
*   **`posts_per_page` for WP_Query:** Hardcoded in PHP (default 10); could be a future attribute.
*   **Dynamic Link Color in Custom RichText:** "Item Link Color" primarily affects links in queried posts. Links in RichText custom items inherit "Item Text Color" or their own RichText formatting.
